# 抢先交易(老鼠仓)监测系统

以 Java 21 实现的券商内部抢先交易监测原型:模拟行情与交易数据,埋入多种
老鼠仓手法,检测引擎从**委托、成交、账户关系、员工信息接触**四个维度出发,
找出可疑交易并输出完整证据链。

## 运行

```bash
javac -d out $(find src -name '*.java')
java -cp out com.broker.frontrun.Main
```

## 架构

```
src/com/broker/frontrun/
├── Model.java      数据模型:品种/账户/员工/关系/委托/成交/信息接触
├── Market.java     行情引擎:随机游走 + 大单冲击 + 板块联动 + 期权杠杆
├── Simulator.java  数据模拟:背景噪音 + 5 种抢跑手法 + 1 个诱饵(ground truth)
├── Detector.java   检测引擎:关联图谱 + 六维打分 + 证据链生成
└── Main.java       入口:运行模拟、输出警报、对照 ground truth 评估
```

## 检测逻辑

以客户大额委托(≥500 万)为触发点,向前 30 分钟滑窗扫描**同向**成交,
对命中账户计算六维特征加权打分:

| 维度 | 权重 | 说明 |
|---|---|---|
| 关联强度 | 0.30 | 账户与**接触过该单信息**的员工之间的最强关系(配偶 0.9 / 父母 0.85 / 共用设备 0.7 / 共用银行卡 0.65 / 朋友 0.6 …) |
| 品种相关 | 0.20 | 同股 1.0 / 标的看涨期权 0.8 / 同板块股票 0.5 |
| 时间接近 | 0.20 | 距客户单越近越高,30 分钟线性衰减(容忍拉长间隔的手法) |
| 规模异常 | 0.15 | 相对该账户历史单笔金额 P95 的异常倍数 |
| 获利情况 | 0.15 | 客户单推动价格后 10 分钟内的浮动收益 |

**报警门槛**:必须存在「信息接触 × 账户关联」链条(rel > 0)且总分 ≥ 0.55。
无关联但统计异常的交易(如量化账户恰好同向)进入**观察名单**,不直接定性——
这是控制误报的关键:市场上大量正常跟风/量化交易没有信息接触证据。

## 埋入的测试场景

- **S1** 配偶账户同股抢跑,客户单前 30 秒
- **S2** 三个关联账户(配偶/朋友/共用银行卡)分散买入,提前 1~4 分钟
- **S3** 拉长时间间隔,提前 22 分钟
- **S4** 改用相关品种:买入标的看涨期权
- **S5** 改用同板块股票
- **D1** 诱饵:员工亲属交易同股但该员工**未接触**此单 → 不应报警(验证信息接触维度的必要性)

当前运行结果:场景召回 5/5,交易级精确率 1.00、召回率 1.00,诱饵未误报。

## 真实系统落地时的扩展点

- **关系图谱**:接入户籍、开户资料、设备指纹、IP/MAC、银行卡、地址等多源数据,
  支持多跳路径(员工→配偶→其名下其他账户)与置信度衰减;关系不完整时用
  图算法(如标签传播)做补全。
- **信息接触范围**:从柜台系统、OA、风控抄送、行情终端日志还原"谁在何时能看到
  哪笔委托",支持按部门/职责推断潜在知悉人。
- **行为基线**:规模异常可换成分位数回归或孤立森林;时间接近度可用历史抢跑
  案例的经验分布代替线性衰减。
- **品种关联**:扩展成分股相关性矩阵、ETF 篮子、可转债、期货等对冲/替代渠道。
- **流式处理**:本原型为批处理;生产环境可用 Flink 做事件驱动的实时滑窗检测。
